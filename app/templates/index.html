ยิงงาน AI ผ่าน API เดียว
เริ่มต้นหลักร้อยต่อเดือน

Thai API Hub คือ API Gateway ที่เข้ากันได้ 100% กับ OpenAI SDK — ด้านหลังสลับให้อัตโนมัติระหว่าง AI ในเครื่องเซิร์ฟเวอร์ (ฟรี), โมเดลฟรีคุณภาพสูง และ โมเดลพรีเมียมราคาถูก จากแหล่ง AI ระดับโลก เจ็บครั้งเดียวย้ายมาใช้งานได้เลย แพงน้อยกว่าหลายเท่า

สมัครทดลองใช้ฟรี ดูเอกสาร API
เริ่มใช้งานใน 30 วินาที

  -H "Authorization: Bearer th-ใส่คีย์ของคุณ" \

  -d '{"model":"thai-hub/auto","messages":[{"role":"user","content":"สวัสดี แนะนำตัวหน่อย"}]}'

🔌

เข้ากันได้กับ OpenAI 100%

เปลี่ยนแค่ base_url กับ API key ในโค้ดเดิมของคุณ ใช้ได้กับ Python, Node.js, Go, PHP และเครื่องมืออย่าง LangChain / n8n ทันที

🔄

สลับโมเดลอัตโนมัติ (Failover)

เซิร์ฟเวอร์สลับไปให้เองตามลำดับ: AI ในเครื่อง → โมเดลฟรี → โมเดลพรีเมียม ไม่มีงานค้างเพราะโมเดลไหนล่มหรือติด rate limit

🏠

Local AI ในเครื่อง ฟรีไม่อั้น

เรารันโมเดลโอเพนซอร์ส (Qwen 2.5) บนเซิร์ฟเวอร์ของเราเอง งานทั่วไปใช้เส้นทางนี้ได้ฟรี ข้อมูลไม่ออกจากบ้าน

💸

ราคาคนไทยจ่ายไหว

เริ่มต้น ฿199/เดือน หรือจ่ายรายปีลดเพิ่ม เทียบกับค่าโมเดลรายใหญ่ที่พุ่งเป็นพันต่อเดือนสำหรับงานหนัก

📊

แดชบอร์ดภาษาไทย

เห็นการใช้งานแบบเรียลไทม์ สร้าง/ยกเลิก API key ได้เอง โควตาเหลือเท่าไร ใช้โมเดลอะไร ค่าใช้จ่ายตกเท่าไร โปร่งใสหมด

คำถามที่พบบ่อย

ต่างจากไปสมัคร OpenAI/Anthropic เองยังไง?

ไม่ต้องสมัครบัตรต่างประเทศ ไม่ต้องจ่ายดอลลาร์ ไม่ต้องดูแลหลายบัญชี — จ่ายบาทเดียวจบ และระบบเลือกโมเดลที่ถูกที่สุดที่งานออกมาดีให้เอง

โมเดลอะไรบ้าง?

เส้นทางฟรีใช้ตัวเก่งๆ อย่าง Llama 3.3 70B, DeepSeek V3, Qwen3, Gemma 3 ส่วนเส้นทางพรีเมียมใช้โมเดลชั้นนำอย่าง DeepSeek V3.1, Gemini Flash, GPT-4o-mini และแพ็กเกจโปรขึ้นไปเลือกโมเดล AI ระดับโลกได้เองทุกตัว

"AI ในเครื่อง" แปลว่าอะไร?

เรารันโมเดลโอเพนซอร์สบนเซิร์ฟเวอร์ของเราเอง คำขอของคุณไม่ต้องออกไปหาบริการภายนอก — เหมาะกับงานทั่วไป ช่วยประหยัดค่าโมเดลได้มหาศาล

จ่ายเงินยังไง? ยกเลิกได้ไหม?

สแกน QR หรือโอนเข้าบัญชีธนาคารจากหน้าบิลในแดชบอร์ด กดแจ้งชำระ แล้วรออนุมัติ หมดสัญญาแล้วไม่ต่อก็จบ ไม่มีบัตรถูกตัดอัตโนมัติ
