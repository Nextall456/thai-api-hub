เอกสารการใช้งาน API

API ของเราใช้รูปแบบเดียวกับ OpenAI Chat Completions — ถ้าโค้ดคุณใช้ OpenAI อยู่แล้ว เปลี่ยนแค่สองค่า:

1) ค่าที่ต้องเปลี่ยน
  • base_url → {{ site_url }}/v1
  • api_key → คีย์ที่ได้จากหน้าแดชบอร์ด (ขึ้นต้นด้วย th-)

เรียกใช้งาน (Chat Completions)

cURL
curl {{ site_url }}/v1/chat/completions \
  -H "Authorization: Bearer th-ใส่คีย์ของคุณ" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "thai-hub/auto",
    "messages": [
      {"role": "system", "content": "คุณเป็นผู้ช่วยพูดไทย"},
      {"role": "user", "content": "สรุปข่าว AI วันนี้ 3 ข้อ"}
    ],
    "temperature": 0.7
  }'
Python (openai SDK)
from openai import OpenAI

client = OpenAI(
    base_url="{{ site_url }}/v1",
    api_key="th-ใส่คีย์ของคุณ",
)

resp = client.chat.completions.create(
    model="thai-hub/auto",
    messages=[{"role": "user", "content": "เขียนแคปชั่นขายกาแฟ"}],
)
print(resp.choices[0].message.content)
Node.js (openai SDK)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "{{ site_url }}/v1",
  apiKey: "th-ใส่คีย์ของคุณ",
});

const resp = await client.chat.completions.create({
  model: "thai-hub/auto",
  messages: [{ role: "user", content: "สรุปงบของฉันเป็น bullet" }],
});
console.log(resp.choices[0].message.content);

แบบสตรีม (เห็นข้อความทยอยไหล)

ใส่ "stream": true ระบบจะส่งแบบ SSE เหมือน OpenAI — ตัวอย่าง cURL:

Streaming
curl -N {{ site_url }}/v1/chat/completions \
  -H "Authorization: Bearer th-ใส่คีย์ของคุณ" \
  -H "Content-Type: application/json" \
  -d '{"model":"thai-hub/auto","stream":true,"messages":[{"role":"user","content":"เล่าตลกสั้นๆ"}]}'

Response Headers (Observability & Rate Limits)

ทุก Request จะมี Response Headers ส่งกลับมาเพื่อความสะดวกในการ Monitor และ Debug:

Headerคำอธิบายตัวอย่าง
X-Thai-Hub-BackendProvider และ Model จริงที่ประมวลผลคำขอopenrouter:google/gemini-2.5-flash-lite
X-Thai-Hub-Latency-Msความเร็ว Latency ในการประมวลผล (ms)245
X-Thai-Hub-Attemptsจำนวน Backend ที่พยายาม (1 = สำเร็จรอบแรก, >1 = มี Failover)1
X-RateLimit-Limit-Requestsโควตาคำขอรายวันตามแพ็กเกจ300
X-RateLimit-Remaining-Requestsจำนวนคำขอรายวันที่ยังเหลืออยู่299
X-RateLimit-Limit-Tokensโควตา Token รายเดือนตามแพ็กเกจ3000000
X-RateLimit-Remaining-Tokensจำนวน Token รายเดือนที่ยังเหลืออยู่2998450
X-RateLimit-Limit-RPMขีดจำกัดความถี่คำขอต่อนาที (RPM)30
