เงื่อนไขการใช้บริการ

อัปเดตล่าสุด: กันยายน 2569 · การใช้บริการถือว่าคุณยอมรับเงื่อนไขทั้งหมดนี้

1. บริการที่ให้

{{ site_name }} ให้บริการ API Gateway สำหรับเรียกใช้โมเดล AI ผ่าน API ที่เข้ากันได้กับ OpenAI SDK โดยระบบจะเลือกโมเดลที่เหมาะสมให้อัตโนมัติ (Local AI และ/หรือโมเดลจากผู้ให้บริการระดับโลก)

2. บัญชีผู้ใช้

  • ต้องสมัครด้วยอีเมลจริง และรักษารหัสผ่านเป็นความลับ
  • ห้ามแบ่งปัน API Key ให้บุคคลอื่นใช้งาน (แต่ละคีย์ใช้โควตาร่วมกันในบัญชี)
  • เราขอสิทธิ์ระงับบัญชีที่ใช้งานผิดปกติหรือละเมิดเงื่อนไข

3. การชำระเงินและการคืนเงิน

  • ชำระผ่านการโอนเข้าบัญชีธนาคาร/สแกน QR ตามหน้าบิล ยอดพอดีตามใบแจ้งหนี้
  • หลังแจ้งชำระ รอผู้ดูแลตรวจสอบและอนุมัติ (ปกติ 1-24 ชม.) แล้วแพ็กเกจเปิดใช้ทันที
  • การซื้อรายเดือน/รายปีไม่ผูกขาด — หมดอายุแล้วไม่ต่อ ก็จบ ไม่มีการตัดบัตรอัตโนมัติ
  • คืนเงินได้กรณีระบบใช้งานไม่ได้จริงและไม่สามารถแก้ไขได้ภายใน 7 วัน โดยติดต่อผู้ดูแลพร้อมรหัสอ้างอิงบิล

4. การใช้งานที่เหมาะสม

  • ห้ามใช้บริการสร้างเนื้อหาผิดกฎหมาย ละเมิดลิขสิทธิ์ หรือเป็นอันตรายต่อผู้อื่น
  • ห้ามพยายามโจมตี ย้อนดูระบบ หรือเลี่ยงโควตาด้วยวิธีที่ไม่เหมาะสม
  • โควตาต่อแพ็กเกจ (คำขอ/วัน, tokens/เดือน, คำขอ/นาที) ถูกบังคับใช้อัตโนมัติ

5. การรับประกันและข้อจำกัดความรับผิด

  • บริการให้ "ตามสภาพ" — เราพยายามให้ระบบพร้อมใช้ตลอดเวลา แต่ไม่รับประกัน 100% ไม่มีข้อขัดข้อง
  • คำตอบจากโมเดล AI อาจไม่ถูกต้องเสมอไป — ผู้ใช้ต้องตรวจสอบก่อนนำไปใช้จริง
  • ความเสียหายที่เกิดจากการใช้คำตอบของ AI ผู้ใช้ต้องรับผิดชอบเอง

6. การเปลี่ยนแปลงเงื่อนไข

เราอาจปรับเงื่อนไข ราคา หรือโควตาได้ตามความเหมาะสม โดยจะแจ้งให้ทราบล่วงหน้าผ่านเว็บไซต์อย่างน้อย 7 วัน (กรณีราคา/โควตา จะไม่กระทบรอบที่ชำระไปแล้ว)

7. การติดต่อ

อีเมลผู้ดูแลปรากฏในหน้าเว็บไซต์ หรือทักแชทบอทอย่างเป็นทางการของ {{ site_name }}
